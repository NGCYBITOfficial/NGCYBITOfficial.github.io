# NGCYBIT Exchange Website

A static English website built with HTML, CSS, and JavaScript for GitHub Pages.

## Deploy

Upload every file and folder in this directory to the root of the `NGCYBITOfficial.github.io` repository. Keep image filenames unchanged. The recovered preview images in `assets/images/` can be replaced with the original high-resolution files using the same names.

## Structure

- `index.html`, `about.html`, `insights.html`, `faq.html`, `contact.html`
- `insights/`: five long-form articles
- `css/style.css`: shared responsive design
- `js/main.js`: navigation, filtering, reveal, contact, and copy interactions
- `sitemap.xml`, `robots.txt`, `.nojekyll`: GitHub Pages and crawler support
